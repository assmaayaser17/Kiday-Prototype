# KIDAY — النموذج التفاعلي (Prototype)

نموذج تفاعلي للتصميم فقط. يبدأ بشاشة تسجيل الدخول (مثل التطبيق)، ومنها «دخول سريع»: موظف · مشرف · ولي أمر.
- **ولي الأمر والمشرف**: الشاشات كما هي في كود التطبيق الحالي.
- **الموظف (المعلمة)**: الشاشات مع التحسينات المقترحة.
- للرجوع لشاشة الدخول: صورة الحساب (الدائرة أعلى الشاشة) ← «تسجيل الخروج».
كل البيانات وهمية (`src/data.js`)، ولا يوجد أي ربط بالباك إند أو قاعدة البيانات.
الألوان والخطوط منقولة من نظام تصميم KIDAY (`packages/ui/src/tokens`).

## التشغيل على جهازك
```bash
npm install
npm run dev        # يفتح على http://localhost:5173
```

## الرفع على Vercel (من حسابك)
الطريقة ١ — من الموقع:
1. ارفعي الفولدر ده على GitHub كـ repo جديد.
2. vercel.com → Add New → Project → اختاري الـ repo → Deploy.
   (Vercel يتعرف تلقائيًا على Vite: Build = `npm run build`، Output = `dist`)

الطريقة ٢ — من الـ Terminal:
```bash
npm i -g vercel
vercel          # أول مرة: يسأل عن الحساب والمشروع
vercel --prod   # الرابط النهائي
```

## الملفات
- `src/screens.jsx` — خريطة الشاشات (T-xx المعلمة، P-xx ولي الأمر، S-xx المشرف).
- `src/screens/orig` — شاشات الطاقم كما في الكود الحالي (يستخدمها المشرف).
- `src/screens/staff|parent|supervisor` — شاشات كل دور.
- `src/data.js` — الحضانة والفصول والطاقم والأطفال (أسماء مخترعة).
- `src/logic.js` — النسب والسجلات والجمل.
- «إعادة ضبط» في اللوحة يرجّع البيانات للبداية.
